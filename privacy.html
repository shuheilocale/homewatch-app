homewatch プライバシーポリシー

最終更新: 2026年11月8日

このアプリについて

homewatch は、作者が自分のためだけに使う個人用のアプリです。利用者は作者 1 人です。

読み取るデータ

作者自身が許可した範囲で、Google Health API から作者自身の次のデータを読み取ります (読み取りのみで、書き込みはしません)。

  • 睡眠 (時刻・長さ・段階)
  • 活動 (歩数など)
  • 健康の測定値 (心拍・安静時心拍・心拍変動・血中酸素など)

使い方と保存場所

読み取ったデータは、作者の家にある機器 (Raspberry Pi) と作者のパソコンにだけ保存し、家の中の画面での表示と、作者自身の振り返りにだけ使います。

共有・販売

データを第三者に共有・販売・提供することはありません。広告にも使いません。

Google API Services User Data Policy

Google API から受け取った情報の利用と他のアプリへの転送は、限定的使用 (Limited Use) の要件を含む Google API Services User Data Policy に従います。

連携の解除・削除

Google アカウントの「サードパーティのアクセス」からいつでも連携を解除できます。解除したあとは新しいデータを読み取りません。保存済みのデータは作者が自分の機器から削除します。

Privacy policy (English summary)

homewatch is a personal app used only by its author. With the author's consent it reads the author's own sleep, activity and health-metric data from the Google Health API (read-only). The data is stored only on the author's own devices at home and used only for display at home and the author's own review. It is never shared, sold, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account's third-party access settings.
